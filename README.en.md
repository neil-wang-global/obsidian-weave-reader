# Weave EPUB Reader

Weave EPUB Reader is a multi-format ebook reader plugin for Obsidian. It unifies reading, excerpting, backlinks, source navigation, and review in one workflow.

Supported book formats include EPUB, MOBI, AZW3, FB2, CBZ, and plain text. Minimum Obsidian version: **1.7.0**.

- Full documentation: [README.md](./README.md)
- 中文版: [README.zh-CN.md](./README.zh-CN.md)

## Installation

### Manual installation

1. Download these files from a [GitHub release](https://github.com/zhuzhige123/obsidian-weave-reader/releases) whose tag matches `manifest.json` (for example `0.6.8`):
   - `main.js`
   - `manifest.json`
   - `styles.css`
   - `versions.json` (recommended)
2. Copy them into `.obsidian/plugins/weave-epub-reader/`
3. Restart Obsidian
4. Enable **Weave EPUB Reader** under **Settings → Community plugins**

### Community plugins (when listed)

Open **Settings → Community plugins → Browse**, search for **Weave EPUB Reader**, then install and enable it.

## Basic usage

1. Enable the plugin under **Settings → Community plugins**.
2. Open the bookshelf from the ribbon icon or command palette, then import or open a book from your vault.
3. Select text in the reader to create excerpts, highlights, or bookmarks.
4. Use the reader toolbar for chapter navigation, display settings, and export actions.
