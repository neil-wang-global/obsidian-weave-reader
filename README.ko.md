## 소개

**Obsidian을 메모 보관함이 아니라, 실제로 책을 읽는 공간**으로 쓰고 싶다면 Weave EPUB Reader를 추천합니다.

읽으면서 Markdown에 문장을 남기는 분, Canvas에 발췌를 정리하는 연구자, Weave로 간격 반복 카드를 만드는 분, 여러 권을 월간 캘린더로 진행하고 싶은 분——「10권 열어 두고 반 페이지씩」이 아니라 계획적으로 읽고 싶을 때 적합합니다.

시작은 가볍습니다. Vault에 EPUB을 넣고, 책장에서 열고, 텍스트를 선택해 발췌하면 됩니다. 각 발췌에는 원서 위치 정보가 붙습니다. 노트를 편집·삭제·색 변경하면 본문 하이라이트도 함께 갱신됩니다. 자동 발췌, Canvas, 카드, 백링크, 점진적 읽기 다섯 가지 워크플로는 아래 [발췌 및 노트 워크플로](#발췌-및-노트-워크플로)를 참고하세요. 자신의 습관에 맞는 경로를 고르면 됩니다.

## 핵심 기능 체크리스트

### 읽기 및 책장

- 데스크톱 / 모바일 전 플랫폼 읽기
- EPUB, TXT, FB2/FBZ 읽기(MOBI, AZW3, CBZ는 프리미엄)
- 내 책장: 가져오기, 표지, 진행률, 검색/필터, 읽기 상태
- 페이지 넘김 / 연속 스크롤, 단일 / 이중 열, 너비와 타이포그래피 조절
- 읽기 진행률 유지, 북마크, 남은 시간 추정
- 단락 읽기 모드, 몰입형 전체 화면, 참조 읽기 포인트(프리미엄)
- 책장 재생목록(프리미엄)

### 발췌 및 주석

- 5색 하이라이트 + 밑줄 / 취소선 / 물결선
- 생각 말풍선(`---div---`)
- 자동 모드: 노트에 삽입 / 클립보드에 복사
- Markdown / Canvas / Weave 덱 본문 반영 및 동기화
- 스크린샷 발췌(페이지를 넘어 이어서 캡처 가능)

### 발췌 요약

- 발췌 카드 목록(필터, 정렬, 원문으로 이동)
- 발췌 타임라인 보기(날짜별 회고, 원문으로 이동)
- 일괄 선택: 내보내기 / 삭제
- 목차 사이드바 전서 맵 밀도 바

### 추적 및 연동

- 발췌에 도서 딥링크 기록
- 정밀 양방향 추적: 노트 ↔ 원서(프리미엄)
- Canvas 연결, 노드 자동 생성, 반영
- 카드 만들기 / 점진적 읽기 / AI(Weave 필요; 리더 프리미엄 라이선스는 소비하지 않음)

### 내보내기 및 보조

- 현재 챕터를 Markdown으로 내보내기(기본)
- 전서 / 현재 챕터 발췌, 표시된 챕터 내보내기(프리미엄)
- 내보내기 템플릿 스튜디오와 내장 프리셋
- 각주 호버 미리보기(프리미엄)
- 다국어 UI(简体中文, 繁體中文, English, 日本語, 한국어, Русский, Deutsch, Español, العربية) + 앱 내 사용 튜토리얼

기능 구분은 [기본 체험과 프리미엄 지원](#기본-체험과-프리미엄-지원)을 참고하세요.

최소 Obsidian 버전: **1.8.7**

## 발췌 및 노트 워크플로

아래 다이어그램은 전체 구조 요약입니다(Mermaid는 **GitHub**와 **Obsidian** 모두에서 렌더링됩니다).

### 그림 1 · 워크플로 선택(목표별)

Obsidian 안에서 읽는 것이 중심이며, 바깥쪽 각 가지는 목표에 따른 전형적인 경로입니다.

```mermaid
flowchart TB
  READ(["Obsidian 안에서 읽기<br/>Weave EPUB Reader"])

  READ --> A["A 자동 Markdown 발췌<br/>어디에 기록할지"]
  READ --> B["B Canvas 시각 정리<br/>구조 그리기"]
  READ --> C["C 기억 복습<br/>카드 만들기"]
  READ --> D["D 백링크 복습<br/>노트 ↔ 원서"]
  READ --> E["E 점진적 읽기<br/>언제 무엇을 읽을지"]

  A --> LOOP["핵심 루프 합류<br/>읽→기록→표시→돌아가기"]
  B --> LOOP
  C --> LOOP
  D --> LOOP
  E --> LOOP
```

### 그림 2 · 점진적 읽기 하위 흐름(워크플로 E)

**여러 권을 일정에 맞춰 진행하는 방법**을 다루며, 자동 발췌(워크플로 A)와 보완 관계입니다: **E가 챕터 일정, A가 기록 내용**을 담당합니다.

```mermaid
flowchart LR
  TOC["목차: 현재 챕터를<br/>점진적 읽기에 추가"]
  CAL["Weave 점진적 읽기<br/>월간 캘린더"]
  MIX["여러 권 · 여러 챕터<br/>교차 일정"]
  DAY["예정일<br/>작업 열기"]
  BOOK["딥링크로<br/>챕터·단락으로 복귀"]
  DEEP["점진적 읽기 포인트 / 이어 읽기 포인트<br/>깊이 읽기"]
  LOOP["읽→기록→표시→돌아가기<br/>발췌 · 백링크 · 반영"]

  TOC --> CAL --> MIX --> DAY --> BOOK --> DEEP --> LOOP
```

### 다섯 가지 전형적인 워크플로

#### A. 자동 Markdown 발췌(가장 일반적)

**읽으면서 노트를 주 전장으로 쓰는** 경우에 적합:

1. **먼저** Markdown 노트를 발췌 노트로 열고, 삽입할 위치에 커서를 둡니다(분할 화면이 가장 좋음).
2. 리더를 열고 툴바의 **자동 모드**를 켭니다(번개 아이콘: 켜짐 = 삽입, 꺼짐 = 클립보드 복사).
3. 책에서 텍스트를 선택해 발췌 → 위치 정보가 있는 발췌 블록(도서 딥링크 포함)이 **해당 커서 위치에 자동 삽입**됩니다.
4. 노트를 저장한 뒤 같은 책을 다시 열면, 해당 단락에 **본문 하이라이트가 표시**됩니다——노트에 기록한 내용이 책을 열면 보입니다.

자세히: 위 [워크플로 A](#a-자동-markdown-발췌가장-일반적).

#### B. Canvas 시각 정리

**주제 정리, 구조 시각화, 논점 관계 파악**에 적합:

1. 현재 책에 Canvas 파일을 **연결**합니다.
2. 자동 모드를 켜면 발췌가 **Canvas 새 노드에 자동 기록**될 수 있습니다(배치 방향 설정 가능).
3. Canvas에서 노드를 배치·연결·그룹화합니다. 리더는 연결된 Canvas의 발췌를 **본문에 반영**합니다.

#### C. 기억 복습

발췌를 **간격 반복**에 넣고 싶을 때 적합:

1. 텍스트 선택 → 툴바 **카드 만들기** → Weave 카드 편집기.
2. `.wdeck` 등 덱 파일에 저장하면 리더가 덱 데이터에서 **하이라이트를 반영**합니다.
3. Weave에서 복습하고, 필요할 때 원문 단락으로 돌아갈 수 있습니다.

#### D. 백링크 복습

**먼저 발췌, 나중에 복습, 다시 원문** 흐름에 적합:

1. Markdown / Canvas / 덱에서 과거 발췌를 확인하고, 책을 열면 **본문에 하이라이트가 표시**됩니다.
2. 노트의 도서 딥링크를 클릭 → **원문 단락**으로 이동합니다.
3. 리더에서 하이라이트를 클릭 → **소스 노트로 바로 이동**(양방향 추적).

#### E. 점진적 읽기: 여러 권 교차와 깊이 읽기

**한 권을 한 번에 끝내지 않고, 여러 권을 리듬 있게 진행**하고 싶을 때 적합:

1. **현재 챕터를 점진적 읽기에 추가**: 리더 사이드바 **목차**에서 챕터에 **「점진적 읽기에 추가」**를 사용합니다(점진적 읽기 주제를 선택할 수 있음).
2. **월간 캘린더에서 일괄 일정**: 챕터가 Weave **점진적 읽기 월간 캘린더**에 나타나며, 다른 책·챕터의 읽기 포인트와 함께 일정에 잡힙니다——책장에 여러 권을 반쯤 열어 두는 대신 **여러 권 교차 읽기**를 구현합니다.
3. **얕은 읽기가 아닌 깊이 읽기**:  
   - 텍스트 선택 → **점진적 읽기 포인트** 생성(EPUB 소스 딥링크 유지);  
   - 읽는 중 **점진적 읽기 이어 읽기 포인트**를 표시해, 다음 점진적 읽기 세션에서 **책의 정확한 위치**로 한 번에 돌아갑니다.  
4. 예정일에 캘린더나 작업 목록에서 해당 항목을 열면 → 딥링크로 챕터/단락으로 돌아와 발췌·백링크 워크플로와 이어집니다.

워크플로 A(읽으면서 기록)와 보완 관계입니다: **A는 「어디에 기록할지」, E는 「언제 어느 챕터를 읽을지, 여러 권을 어떻게 번갈아 진행할지」**를 담당합니다.

### 「외부 리더 + 수동 붙여넣기」와 비교하면

- **컨텍스트 전환이 적음** — 한 문장을 적기 위해 Obsidian을 떠날 필요가 없습니다.
- **발췌가 Vault에 축적·검색 가능** — Markdown / Canvas / 덱에 남으며 클립보드 기록에 흩어지지 않습니다.
- **복습 때도 원문이 곁에 있음** — 노트는 색인, 책은 현장; 딥링크와 본문 반영으로 연결됩니다.
- **기기 간 같은 워크플로** — 책과 노트는 Vault에 있으며 Obsidian 동기화 설정을 따릅니다.
- **장편·여러 권에 리듬** — 챕터를 점진적 읽기 캘린더에 넣어 일정에 맞춰 교차 진행합니다.

자세한 내용: 위 [발췌 및 노트 워크플로](#발췌-및-노트-워크플로)와 [핵심 기능 체크리스트](#핵심-기능-체크리스트).

## 설치

### 방법 1: 커뮤니티 플러그인(권장)

1. **설정 → 커뮤니티 플러그인 → 찾아보기** 열기
2. **Weave EPUB Reader** 검색 후 설치하고 활성화

### 방법 2: 수동 설치

1. [GitHub Releases](https://github.com/zhuzhige123/obsidian-weave-reader/releases)에서 `manifest.json` 버전과 일치하는 릴리스 다운로드:
   - `main.js`
   - `manifest.json`
   - `styles.css`
2. `.obsidian/plugins/weave-epub-reader/`에 복사
3. Obsidian을 다시 시작하고 **설정 → 커뮤니티 플러그인**에서 **Weave EPUB Reader** 활성화

## 빠른 시작

1. 리본 또는 명령 팔레트에서 **책장**을 연 뒤, Vault에서 책을 가져오거나 엽니다.
2. Markdown 파일을 만들거나 열고 발췌를 넣을 위치에 커서를 둡니다. 리더에서 **자동 발췌**를 켭니다. 텍스트를 선택해 하이라이트·발췌·북마크를 만들면 해당 위치에 자동 삽입됩니다.
3. 본문 하이라이트를 클릭해 툴바에서 소스 노트로 이동하고, 발췌가 저장된 Markdown / Canvas에서 옆의 책 아이콘을 클릭하면 책의 해당 위치로 돌아갑니다.
4. 리더 메뉴 → **도움말** → **튜토리얼**에서 앱 내 안내를 확인하세요. 워크플로 세부 사항은 위 [발췌 및 노트 워크플로](#발췌-및-노트-워크플로)를 참고하세요.

## 데이터와 동기화

**동기화 권장(Vault 내)**: 도서 파일, Markdown 발췌, Canvas, Weave 덱 데이터, 그리고 책별 진행률·북마크 전용 노트(기본 `Weave EPUB Reader/data_*.md`).

**보통 로컬(플러그인 폴더)**: 리더 캐시, 인덱스, Canvas 연결, 참조 읽기 포인트 등 로컬 상태. 기기 간에는 Vault 내용 동기화를 우선하고, `.obsidian/plugins/weave-epub-reader/` 캐시 파일은 직접 동기화하지 않는 것을 권장합니다.

## 개인정보와 네트워크

- 읽기, 렌더링, 발췌, 백링크는 **기본적으로 로컬**에서 처리되며 Vault 내용을 능동적으로 업로드하지 않습니다.
- 책장, 백링크, 소스 위치 찾기 기능은 로컬에서 Vault 파일 경로를 열거하며, 발췌나 활성화 코드 복사 시 클립보드에 접근합니다. [PRIVACY.md](./PRIVACY.md) 참고.
- **프리미엄 지원 활성화**는 라이선스 서비스에 연결할 수 있습니다(활성화 코드, 이메일, 기기 지문 요약 등). [PRIVACY.md](./PRIVACY.md) 참고.
- **AI 기능**은 사용자가 설정한 서드파티 서비스를 호출합니다.

## 자주 묻는 질문

### 독서 발췌 노트를 올바르게 남기려면?

발췌는 선택한 Markdown, Canvas, Weave 덱 파일의 구체적 위치에 저장됩니다. 리더는 그 발췌들의 소스 링크를 모아 본문에 하이라이트를 반영합니다. 이 저장 조건을 충족하지 않는 선택은 잠깐만 하이라이트되고, 동기화 가능한 실질 데이터는 남지 않습니다. 리더 상단 튜토리얼 배너에 더 자세한 설명이 있습니다.

### Weave와의 관계는?

**Weave EPUB Reader는 단독으로 동작합니다**: [Weave](https://github.com/zhuzhige123/anki-obsidian-plugin) 메인 플러그인 없이도 Obsidian에서 EPUB을 읽고, 책장을 쓰며, 기본 발췌와 본문 반영이 가능합니다. Weave를 설치하면 간격 반복 카드, 점진적 읽기 캘린더, AI 메뉴 등에 연결할 수 있고, Weave 라이선스를 상속해 프리미엄 지원을 켤 수 있습니다. 둘은 **선택적 연동**이며 필수 의존이 아닙니다.

### 발췌 노트는 전 플랫폼에서 동기화되나요?

**예.** 발췌는 Vault 내 Markdown, Canvas, 덱 등에 저장되며 Obsidian Sync, iCloud, Vault 동기화 등 사용 중인 방식에 따라 데스크톱과 모바일 간에 일치합니다. Vault 내용 동기화를 권장하며, 리더 캐시 등 플러그인 폴더 데이터는 보통 기기 간 동기화가 필요 없습니다(위 [데이터와 동기화](#데이터와-동기화) 참고).

### 노트를 내보낼 수 있나요?

**예.** 발췌와 하이라이트 데이터는 Vault에 저장되어 Obsidian에서 직접 보고·편집·Markdown 내보내기가 가능하며, 리더에도 챕터 내보내기 등이 있습니다. **데이터는 기본적으로 완전 로컬**이며 Vault 내용을 능동적으로 업로드하지 않습니다.

### 왜 프리미엄은 유료인가요?

프리미엄 지원은 **지속적인 개발을 지원**하기 위한 것입니다——개발자가 장기적으로 읽기·발췌 경험을 다듬을 수 있도록. **기본 체험은 무료**이며 일상 읽기, 5색 하이라이트, 주석, 발췌, 본문 반영 등 핵심 기능을 충분히 쓸 수 있습니다. 다중 형식, 양방향 추적, 단락 읽기 모드 등 고급 기능이 필요할 때만 프리미엄 지원을 켜면 됩니다.

### 구독인가요, 일회 구매인가요?

프리미엄 지원은 **일회 구매**(한 번 활성화하면 장기 사용; [프리미엄 지원 약관](./PREMIUM_TERMS.md) 참고)이며 월 구독이 아닙니다.

### EPUB이 아닌 형식이 열리지 않나요?

**EPUB, TXT, FB2/FBZ**는 기본 체험에 포함됩니다. **MOBI, AZW3, CBZ** 등은 프리미엄 지원이 필요합니다. 위 [기본 체험과 프리미엄 지원](#기본-체험과-프리미엄-지원)을 참고하세요.

### 플러그인 폴더 이름은?

플러그인 ID: `weave-epub-reader` → `.obsidian/plugins/weave-epub-reader/`
