# 0. 产品介绍与工作流

## 插件是什么

Weave EPUB Reader 是 Obsidian 内的**多格式电子书阅读器插件**。它把「在书里读 → 在笔记里记 → 从笔记回到书里 → 在正文里看见历史摘录」收成一条链路，而不是把阅读器和笔记拆成两个互不相干的工具。

你可以把它理解成：**阅读发生在 Obsidian 里，摘录天然落在你的 Vault 里，溯源信息跟着走。**

## 适合谁

- 希望在 Obsidian 内直接阅读 EPUB 等书籍，而不是切到外部阅读器
- 阅读时要写摘录、高亮、批注，并希望这些内容进入 Markdown / Canvas / 牌组
- 需要「从笔记一点就回到原书段落」，或「打开书就看见以前记过的重点」
- 已使用或计划使用 **Weave** 做记忆回顾、增量阅读、AI 辅助

## 产品价值（解决什么问题）

| 痛点 | 本插件的做法 |
|------|----------------|
| 阅读与笔记割裂 | 摘录带定位写入 Vault；再打开书时正文回显高亮 |
| 回顾时找不到原文 | 生成 EPUB 深链接；笔记中的链接可跳回精确位置 |
| 视觉整理困难 | 可绑定 Canvas，摘录自动落成节点（高级） |
| 只想记住重点 | 可送入 Weave 记忆牌组，进入复习流程（需 Weave） |
| 长文难以专注 | **段落阅读模式**：单段聚焦、段内翻屏、跨段切换（高级） |

## 典型工作流

结构图（Mermaid，GitHub / Obsidian 可渲染）见仓库 [README.zh-CN · 摘录笔记工作流](../../../README.zh-CN.md#摘录笔记工作流装上之后有什么不同)：**图 1 核心闭环**、**图 2 五流选型**、**图 3 增量阅读子流程**。

### 工作流 A：自动化 Markdown 摘录

适合「边读边记、笔记就是主战场」：

1. 在 Obsidian 中打开一本**目标 Markdown 笔记**（作为摘录容器），光标放在要插入的位置。
2. 打开 EPUB 阅读器，开启工具栏 **自动模式**（闪电图标：开 = 插入，关 = 复制）。
3. 在书中选中文本 → 高亮或摘录 → 内容**自动插入到上一步 Markdown 的光标处**。
4. 保存笔记后，再次打开该书，正文会回显对应高亮。

详见 [自动化摘录流程](./03-auto-excerpt-workflow.md)。

### 工作流 B：Canvas 视觉整理

适合「做专题、画结构、看关系」：

1. 为当前书**绑定**一个 Canvas 文件（高级能力）。
2. 开启自动模式后，摘录可**自动写入 Canvas 新节点**。
3. 在工具栏调整 **Canvas 节点排布方向**（下 / 右 / 上 / 左）。
4. 阅读器识别绑定 Canvas 中的摘录，并回显到正文。

### 工作流 C：记忆回顾（Weave 牌组）

适合「摘录后要复习、要间隔重复」：

1. 选中文本 → 工具栏 **制卡**（或高亮后制卡）。
2. 内容进入 Weave **记忆卡片创建**窗口（需安装 Weave）。
3. 保存到 `.wdeck` 等牌组文件后，阅读器会从牌组数据回显高亮。
4. 在 Weave 的记忆模块中按牌组规则做**记忆回顾**。

摘录写入牌组时，插件会保留 EPUB 语义来源与牌组持久化路径（二者分离，便于同步与溯源）。

### 工作流 D：回链复盘

1. 在笔记或 Canvas 中查看历史摘录；正文侧**回显高亮**（免费）。
2. 在笔记中点击书籍深链接 → 回到原文段落。
3. 在阅读器中从某条高亮**一键定位到来源笔记**（**高级**）。
4. 继续阅读或修改笔记。

### 工作流 E：增量阅读（多书交错、深度精读）

适合同时推进多本书、或长书按章节节奏阅读（**需安装 Weave**）：

1. 在阅读器**目录**中对当前章节使用 **「添加到增量阅读」**（可选专题），将本章纳入增量阅读任务。
2. 在 Weave **增量阅读月历视图** 中与其他书籍章节一起排期，实现**多书交错阅读**。
3. 选区可创建**增量阅读点**（保留 EPUB 溯源链接）；阅读中可标记**增量阅读续读点**，下次从 IR 流程回到书中精确位置。
4. 调度日从月历/任务列表打开 → 经深链接继续读，并与摘录、回链工作流衔接。

阅读器提供入口（不单独占用阅读器高级许可）；月历调度与任务队列由 Weave 增量阅读模块提供。详见 [联动与扩展 · 增量阅读](./06-integrations.md)。

## 与 Weave 主插件的关系

| 维度 | Weave EPUB Reader（本插件） | Weave 主插件 |
|------|---------------------------|--------------|
| 定位 | 专注**读书 + 摘录 + 回链** | 学习、记忆、增量阅读、AI、牌组等**完整套件** |
| 是否必须同时安装 | **否**。可单独使用本阅读器 | 可选。部分能力需主插件 |
| 授权 | 可用 **EPUB 独立激活码** | 主插件激活后，阅读器可**继承共享授权** |
| 典型协作 | 阅读器中「制卡」「增量阅读续读点」「AI 选区菜单」 | 提供记忆牌组、IR、AI 等后端能力 |

**单独安装本插件时**：EPUB 基础阅读、摘录写入 Markdown、教程与搜索等仍可用；制卡、增量阅读入口、AI 拆分菜单等会提示需要 Weave。

**同时安装且主插件已激活时**：无需重复输入同一激活码即可解锁阅读器高级能力（具体以设置页授权状态为准）。

## 全平台支持

本插件随 **Obsidian 全平台**分发使用，与 Obsidian 一致，包括但不限于：

- Windows、macOS、Linux 桌面端
- Android、iOS 移动端

书籍文件、摘录笔记、Canvas、牌组数据位于你的 **Vault** 中，可通过 Obsidian 同步（官方同步、iCloud、Syncthing 等，由你自行配置）。阅读器本地状态（部分进度缓存等）通常在插件目录，详见 [README 数据说明](../../../README.zh-CN.md#数据与同步说明)。
