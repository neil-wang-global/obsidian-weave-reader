# 6. 联动与扩展

## 导出为 Markdown

阅读器视图菜单中的导出入口：

| 功能 | 分层 |
|------|------|
| **导出本书高亮摘录** | 免费 |
| **导出当前章节**为 Markdown | **高级** |

**导出笔记模板**（设置 → 基础）：模板 1 / 模板 2，随摘录能力使用。

## 截图

- 截图模式下在阅读区域拖拽框选。
- **图片模式**：保存为图片；自动模式开启时可直插笔记。
- **嵌入模式**：尽量提取文字并生成带定位的引用。

## Canvas（高级）

- 可为当前书**新建** Canvas 脑图，或**绑定**已有 Canvas（`epub-canvas-excerpts`）。
- 绑定后可打开、继续编辑或断开；配合自动模式可自动落节点。
- 节点排布方向见 [自动化摘录流程](./03-auto-excerpt-workflow.md)。

## Weave 主插件（可选）

本仓库为**独立阅读器**；以下能力需在 Obsidian 中另行安装并启用 **Weave**：

| 能力 | 说明 |
|------|------|
| **制卡 / 记忆牌组** | 选区 → 记忆卡片创建 → 保存 `.wdeck` → 阅读器回显高亮 → 在 Weave 中复习 |
| **增量阅读** | 目录 **「添加到增量阅读」**（当前章节进入 IR 任务与**月历视图**调度）；选区创建**阅读点**；工具栏/菜单 **增量阅读续读点**（保留 EPUB 深链接，供多书交错与深度精读） |
| **AI** | 选中文本拆分菜单、AI 面板（需 API Key） |
| **授权继承** | 主插件已激活时，阅读器可共享高级权限 |
| **`.wdeck` 同步** | 牌组摘录与正文高亮联动（持久化路径与 EPUB 语义来源分离） |

关系说明见 [产品介绍 · 与 Weave 的关系](./00-introduction.md#与-weave-主插件的关系)。

未安装 Weave 时：EPUB 阅读、Markdown 自动摘录、教程与搜索仍可用；制卡 / IR / AI 会提示需要 Weave。

## AI 入口

- 选中文本后可进入 AI 相关操作（**需安装 Weave**；不单独要求阅读器高级版，但 Weave 自身可能有授权要求）。
- 通常需自行配置第三方 AI 服务的 API Key。
- 插件侧问题（按钮、面板、配置读写）与服务商问题（额度、模型不可用）请区分后反馈，见 [SUPPORT.md](../../../SUPPORT.md)。

## 阅读器常用菜单入口（摘要）

| 入口 | 作用 |
|------|------|
| 侧边栏 | 目录、笔记、书签、书架 |
